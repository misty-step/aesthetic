Chart library evaluation — Observable Plot

Each pair sets the current CSS-only instrument beside the same data drawn by Observable Plot, skinned to the law: ink on paper, hairlines, radius 0, one 13px mono register, tabular numerals, accent spent once. See README.md in this directory for the full evaluation.

1 · trend

.ae-spark draws a pen stroke with no axes — perfect for an inline figure, but it cannot carry ticks, multiple series, or a hover readout. Plot's line mark gives the same ink stroke plus a real axis when the surface needs one.

css-only.ae-spark

spend · today

No axis, no scale, no legend — a glance figure only.

observable plotline + dot

Two named series, ticked axis, hover readout.

2 · bar

The kit has no bar primitive today — .ae-meter is a single-value gauge, not a categorical comparison. Plot's barY mark fills the gap: square corners, ink fill, a status ink only where the value crosses a threshold.

css-only.ae-meter × 5 (closest today)

pathfinder

mason

scribe

bursar

courier

Meters stacked to fake a bar chart — no shared baseline axis, no category ticks.

observable plotbarY

Shared baseline, ticked value axis, square bars — no radius, no gradient fill.

3 · scatter + frontier

.ae-plot is hand-authored SVG — the consumer computes the projection and the frontier path themselves. Plot computes the scales and can still leave the frontier line and glyph styling to us; the markup shape (ticks, dashed frontier, accent pick, dominated fade) carries over almost verbatim.

css-only.ae-plot (hand-authored svg)

Frontier and projection computed by hand.

observable plotdot + line + text

Same visual grammar; scales computed for us.

4 · interval / range band

.ae-ci composes a wash band, an ink mean tick, and a hover-revealed exact readout on a single-row track. Plot's rectY + ruleY marks give the same band-and- tick grammar across a shared axis when several intervals need to sit on one scale.

css-only.ae-ci

sonnet · v4

μ 86.9 [83.1, 90.7]

opus · v4

μ 85.6 [82.9, 88.3]

Each interval is its own row/track.

observable plotrectY + ruleY

All intervals share one scale — direct comparison.
