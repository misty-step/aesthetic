# Misty Step brand

The Misty Step brand configurator lives here now. It renders the real studio and mistystack home pages, with independently selectable marks, typefaces, colour, layout, heroes, motion and copy.

The chosen identity will live beside it later, as the shared source for both sites.

## Run the configurator

```sh
cd configurator
npm install
npm run dev
```

See [the configurator guide](configurator/README.md) for option authoring, the rendering contract, verification and the isolated preview deployment.

This repository is separate from the archived `misty-step/aesthetic` design system. The configurator explores its successor; it does not deploy either production site.
